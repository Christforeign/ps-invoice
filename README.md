# Ps Invoice

Build a complete professional web application called "PRIME SHIPPING INVOICE SYSTEM". This application is ONLY for PRIME SHIPPING. Do NOT create login, registration, authentication, user accounts or password protection. The application should open directly to the Prime Shipping invoice dashboard. The goal is to create, calculate, save, search, print, download and share professional Prime Shipping invoices using the provided Prime Shipping invoice design as the main visual reference. IMPORTANT: This is an invoice management system, not a generic accounting system. Focus on making the invoice creation process extremely fast, simple, accurate and professional. COMPANY INFORMATION: Create a dedicated Prime Shipping business profile/settings section where the administrator can configure and edit: Prime Shipping logo, business name, address, city, country, phone number, WhatsApp number, email address, website, tax/registration number, invoice prefix, next invoice number, currency, secondary currency, exchange rate, default notes, default payment terms, footer text, colors, fonts and invoice design. The logo must be uploadable and replaceable. All business information must automatically appear on generated invoices. INVOICE NUMBER: Create automatic invoice numbering. Allow the administrator to define the invoice prefix and starting/next number. Example prefix: INV-PS. Example number: INV-PS0001, then INV-PS0002, INV-PS0003, etc. Never generate duplicate invoice numbers. After an invoice is created, its invoice number must remain permanently attached to that invoice. Allow the administrator to change the next number from Settings when necessary. INVOICE CREATION: Create a fast invoice creation page. The invoice must include: invoice number, invoice date, due date if needed, customer name, company name, phone, WhatsApp, email, customer address, notes and payment information. Allow saving customers for future invoices and searching/selecting an existing customer. PACKAGE SYSTEM: Prime Shipping invoices must support a minimum of 1 package and a maximum of 20 packages. Start with ONE package line by default. The user can click "+ Add Package" to add another line, up to 20 total packages. The user can remove any package line. If the invoice has 1 package, the final PDF must show only 1 package row. If it has 5 packages, show only 5 rows. If it has 10 packages, show only 10 rows. If it has 20 packages, show all 20 rows. NEVER show unnecessary empty package rows on the final invoice. Each package line must have independent information. PACKAGE LINE FIELDS: Each package line must support: package number, tracking number, description, item/product name, quantity, weight, weight unit, shipping rate, shipping cost, customs/duty, service fee, discount if applicable, line total and notes. Support weight units: lb, oz, kg and g. Allow automatic conversion between units. WEIGHT CALCULATION: The system must automatically calculate shipping cost based on weight and rate. Example: Weight = 2.5 lb, Rate = $5.80/lb, Shipping Cost = $14.50. The calculation must happen immediately when the user changes weight or rate. If the user changes 2.5 lb to 3 lb, the shipping cost must automatically update to $17.40. LINE-BY-LINE AUTO CALCULATION: Every package line must calculate its own values automatically. When the user changes quantity, weight, weight unit, rate, customs, service fee, discount or any numeric field, immediately recalculate that line and update the invoice totals. If a line is deleted, automatically update all totals. If a line is added, automatically update all totals. Do not require manual calculations. TOTAL CALCULATIONS: Automatically calculate total weight, total shipping cost, total customs/duty, total service fees, total discounts, subtotal, taxes if enabled, grand total, amount paid and remaining balance. All calculations must update in real time. Support decimal values such as 0.25 lb, 1.5 lb, 2.75 lb, etc. CURRENCY: Support USD as the main currency and HTG as a secondary currency. Allow the administrator to define the USD/HTG exchange rate. Example: USD rate = 132.50 HTG. Automatically calculate the HTG equivalent when enabled. Show USD and HTG totals clearly on the invoice. PAYMENT: Add amount paid and remaining balance. Example: Invoice total = $150. Amount paid = $50. Remaining balance automatically becomes $100. If amount paid equals total, automatically mark invoice as PAID. If amount paid is less than total, mark PARTIALLY PAID. If amount paid is zero, mark UNPAID. Prevent incorrect calculations. PAYMENT METHODS: Include Cash, Card, Bank Transfer, MonCash, NatCash, Check and Other. Allow adding custom payment methods. Store the selected payment method with every payment. Allow partial payments. Allow split payments if necessary. Example: Cash $50 + MonCash $50 + Bank Transfer $50 = $150 total paid. Store each payment separately. CUSTOMER INFORMATION: Include customer name, company name, phone, WhatsApp, email, billing address, shipping address and notes. Allow customer search and customer history. CUSTOMER DATABASE: Save customers for future invoices. Each customer record should contain name, company, phone, WhatsApp, email, address, city, country, notes, invoice history, total invoiced, total paid and outstanding balance. PRIME SHIPPING DESIGN: Use the uploaded Prime Shipping invoice image/design as the primary visual reference. Recreate the layout professionally while making every field dynamic. The design should include the Prime Shipping logo, business information, customer information, invoice number, date, package table, tracking numbers, weights, rates, shipping costs, customs, service fees, subtotal, total, payment information, balance, USD/HTG conversion, notes and footer. Keep the visual appearance professional and clean. DESIGN CUSTOMIZATION: Create a Settings > Invoice Design section where the Prime Shipping administrator can customize: logo, logo size, logo position, business name, address, phone, email, WhatsApp, colors, fonts, font sizes, table borders, table headers, header text, footer text, notes, payment instructions and visibility of invoice fields. Allow the user to enable/disable fields without changing the application code. Allow the administrator to save multiple Prime Shipping invoice templates if desired. INVOICE HISTORY: Every generated invoice must be saved automatically. Create an invoice history page with a searchable table. Show: invoice number, customer, date, total, paid, balance, payment method and status. Search by invoice number, customer name, phone, email, tracking number or date. Add filters for Paid, Partially Paid, Unpaid, Cancelled and date ranges. Each invoice must be viewable again after creation. INVOICE ACTIONS: For every saved invoice provide: View, Edit, Duplicate, Download PDF, Print, Send Email, Send WhatsApp, Record Payment and Cancel/Void. Duplicating an invoice must create a NEW invoice number automatically. Do not duplicate the old invoice number. CANCELLATION: Do not permanently delete financial invoices. Use Cancel/Void and keep the original invoice history. PDF GENERATION: Generate a professional PDF using the Prime Shipping template. The PDF must contain only the package lines actually used. Example: 3 packages = exactly 3 package rows. 20 packages = exactly 20 package rows. Do not display unused blank rows. PDF filename example: "INV-PS0025 - Jean Pierre.pdf". PRINTING: Add a professional Print button. When printing, remove unnecessary application interface elements and print only the invoice. EMAIL: Add an Email Invoice button. Allow the user to enter or use the customer's saved email address. Generate the PDF and attach it automatically to the email. Use a customizable email subject and message. WHATSAPP: Add a WhatsApp button. Use the customer's WhatsApp number if available. Automatically prepare a WhatsApp message containing customer name, invoice number, total, amount paid and remaining balance. Example: "Hello Jean, here is your Prime Shipping invoice INV-PS0025. Total: $150.00. Paid: $50.00. Balance: $100.00. Thank you." Open WhatsApp with the prepared message. DASHBOARD: Create a simple Prime Shipping dashboard showing: Total invoices, today's invoices, total invoiced amount, total paid, outstanding balance, paid invoices, partially paid invoices, unpaid invoices and recent invoices. Add quick buttons: "+ New Invoice", "Customers", "Invoice History", "Settings". SEARCH: Create a global invoice/customer/tracking search bar. The user should be able to type an invoice number such as INV-PS0025, a customer name, phone number or tracking number and immediately find the related invoice. TRACKING SEARCH: Tracking numbers must be searchable. If a customer asks about a package, the administrator can search the tracking number and immediately open the related invoice/package information. PACKAGE DETAILS: Every package should support tracking number, description, weight, quantity, shipping rate, shipping cost, customs, service fee and notes. The system must allow up to 20 packages per invoice. VALIDATION: Validate all numeric fields, weights, rates, quantities, payments and required customer information. Do not allow invalid values. Show clear error messages. Use precise decimal calculations for money and weight. Do not use unreliable floating-point calculations for financial totals. RESPONSIVE DESIGN: The application must work perfectly on Android, iPhone, tablet and desktop. The invoice creation page must be especially easy to use on a phone. Make package rows easy to add, edit and remove on mobile. DATA STORAGE: Use a real database or persistent storage. Invoices must remain saved after refreshing or reopening the website. Store invoices, invoice items/packages, customers, payments, settings, invoice templates and activity history. ACTIVITY HISTORY: Record important actions such as invoice created, invoice edited, invoice duplicated, payment recorded, invoice cancelled, invoice number changed and template settings changed. Store date, time, action and reference. IMPORTANT USER EXPERIENCE: The user should be able to create a normal invoice in as few steps as possible. Workflow: 1. Click New Invoice. 2. Select or create customer. 3. Enter package information. 4. Add up to 20 package lines if needed. 5. System automatically calculates every line and all totals. 6. Enter amount paid and payment method. 7. System automatically calculates balance and payment status. 8. Click Generate Invoice. 9. Invoice is saved permanently. 10. PDF is generated. 11. User can download, print, email or WhatsApp the invoice. SETTINGS: Create settings for Prime Shipping business information, invoice numbering, currency, exchange rate, payment methods, invoice design, email settings and WhatsApp settings. IMPORTANT: Do not add login, registration, authentication, user accounts, POS, inventory, expenses, payroll or unrelated accounting modules in this version. This is ONLY a Prime Shipping invoice management system. The system must be fully functional, not a static mockup. Every button must work. Every form must save data. Every calculation must update automatically. Every invoice must be stored. Every invoice number must be unique. Every package line must calculate independently. Maximum 20 package lines per invoice. The uploaded Prime Shipping invoice design must be used as the main design reference, with all business information, logo, address, customer information, package information, calculations, payment information and branding fully editable.
